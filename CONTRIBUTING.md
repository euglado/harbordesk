# Contributing

Thanks for helping improve HarborDesk.

## Development

1. Open an issue before making a substantial behavior change.
2. Keep Discord permissions narrow and explain any new permission in the README.
3. Add or update tests for behavior changes. Tests must not require a live Discord token or server.
4. Run `npm ci` and `npm run check` with Node.js 24.17 or newer.
5. Run `npm audit --audit-level=high` and update documentation when setup or permissions change.

## Pull requests

Explain the user problem, behavior, and security or privacy impact. Do not include real bot tokens, server IDs, private ticket contents, or screenshots containing member data. Keep messages and mentions safe by default.
